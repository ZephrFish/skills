# Base Planning

## Summary

Planning, brainstorming, requirements clarification, and plan-grilling workflows for all Skills OS users.

## What this contains

### Included skills

- `planning-collab-brainstorm` — Collaborative Markdown/Obsidian brainstorming, research, planning, and handoff synthesis.
- `planning-grill` — Stress-test plans, designs, proposals, and roadmaps through a one-question-at-a-time interrogation loop.

### Planned skill areas

- `requirements-clarifier`
- `acceptance-criteria-builder`

## Recommended agents

- None required. Role profiles may recommend optional top-level planning or architect agents.
