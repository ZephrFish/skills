# Base Quality

## Summary

General preflight, readiness, review, and quality-gate workflows for all Skills OS users.

## What this contains

### Included skills

- `git-preflight` — Pre-commit and pre-edit git checklist — staged diff code-review, macOS case renames, remote branch sync verification. Run before committing or starting work on a feature branch.

### Planned skill areas

- `general-readiness-check`
- `handoff-quality-check`

## Recommended agents

- None required. Relevant role profiles may recommend optional top-level agents.
