# Base Skill Building

## Summary

Skills OS workflows for creating, requesting, submitting, and deriving reusable skills from real sessions.

## What this contains

### Included skills

- `skill-submission-prep` — Prepare existing skills or drafts for repository review without approving them.
- `skill-request-builder` — Turn missing workflows, gaps, or role needs into clear skill requests.
- `workflow-to-skill` — Distill completed conversations, sessions, or operator workflows into concrete repo skills.

### Planned skill areas

- Skill improvement helper for revising existing skills after real use.
- Skill quality checklist / validation helper.
- Skill catalog/index update helper if repo cataloging becomes more formal.

## Recommended agents

- None required. Skill authors may use `planner`, `researcher`, or domain-specific agents depending on the target plugin.
