# Base Research

## Summary

Source discovery, source evaluation, claim verification, and synthesis workflows for all Skills OS users.

## What this contains

### Included skills

- `source-research` — Fast topic research with source discovery, source quality evaluation, and concise synthesis. Use when looking up recent information, comparing sources, or producing a quick/detailed summary with citations.

### Planned skill areas

- `deep-research-brief`
- `source-map-builder`
