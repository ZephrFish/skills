# Base Documentation

## Summary

Documentation, README, technical writing, editing, and publishing-support workflows for all Skills OS users.

## What this contains

### Included skills

- `readme-generation` — Generate a professional README.md for a project. Works on local codebases and remote GitHub repos. Use when a project needs a README, when an existing README is outdated, or when documenting someone else's tool.

### Planned skill areas

- `docs-outline`
- `technical-edit`
- `changelog-draft`

## Recommended agents

- None required. Relevant role profiles may recommend optional top-level agents.
